# Task 3 – Deep-Dive Analysis & Interactive Dashboarding

## 📌 Objective
The objective of this task was to perform an in-depth business analysis by identifying key performance indicators (KPIs), applying advanced analytical techniques, and building an interactive Power BI dashboard to generate meaningful business insights.

---

## 🛠️ Tools & Technologies Used

- Power BI
- Microsoft Excel
- SQL
- DAX (Data Analysis Expressions)

---

## 📂 Dataset Description

The dataset contains customer, product, sales, and order-related information including:

- Order ID
- Customer ID
- Customer Name
- Gender
- Age
- City
- Product
- Category
- Quantity
- Unit Price
- Total Sales
- Order Date

---

# 📈 Key Performance Indicators (KPIs) Created

The following KPIs were created using DAX measures:

- Total Sales
- Total Orders
- Total Customers
- Average Order Value
- Average Quantity per Order
- Average Age
- Male Customers
- Female Customers
- Current Month Customers
- Previous Month Customers
- High Value Customers
- Top Product Sales
- Lowest Product Sales
- Average Unit Price
- Sales Growth %
- Quantity Growth %
- Price Growth %
- Male Customer %
- Female Customer %

---

# 🔍 Deep-Dive Analysis Performed

### 1. Customer Segmentation Analysis
- Analyzed customer groups based on purchasing behavior.
- Identified high-value customers and customer patterns.

### 2. Funnel Analysis
- Studied customer journey and purchasing conversion patterns.

### 3. Monthly Sales Trend Analysis
- Compared monthly sales performance.
- Identified growth and decline trends.

### 4. Product Performance Analysis
- Analyzed best-performing and low-performing products.
- Compared sales contribution by products and categories.

### 5. City-wise Sales Analysis
- Evaluated sales performance across different cities.

### 6. Customer Retention Analysis
- Measured customer retention and churn behavior.

---

# 📊 Interactive Power BI Dashboard

An interactive dashboard was created with the following features:

### Dashboard Components:
- KPI Cards
- Sales Trend Charts
- Category-wise Sales Analysis
- City-wise Sales Analysis
- Product Performance Analysis
- Customer Demographic Analysis
- Interactive Filters and Slicers

The dashboard enables users to explore sales performance and customer insights dynamically.

---

# 📌 Key Insights

- Identified top-performing products and categories.
- Analyzed customer purchasing behavior and demographics.
- Compared monthly sales performance trends.
- Measured customer retention and churn patterns.
- Tracked business growth using KPI indicators.
- Generated actionable insights to support business decisions.
